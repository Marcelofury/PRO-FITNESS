# PROFITNESS MOBILE APP
- This a fitness android app developed using kotlin
- **Theme/Slogan**: "Train Like a Pro, Track Like an Elite"
  

 ## Conceptual Framework
 ### Basic Project Information
 **Target Users/Audience**: The application is designed for fitness enthusiasts, professional athletes, and health-conscious individuals who require a structured, data-driven approach to physical training.
 ### Application Description
Pro Fitness is a  mobile health solution that provides users with a professional-grade training environment through a high-fidelity, dark-themed interface. The application guides users through a comprehensive five-step onboarding journey to calibrate personal health metrics and training intensities. By selecting specific goals such as fat loss, muscle hypertrophy,  endurance, users receive a tailored experience that moves beyond generic fitness tracking. The unique value of this application lies in its "Elite UI" philosophy, which uses high-contrast Electric Cyan accents against a deep dark-green background to improve focus and readability during intense workouts.
### Core Functionalities
- **Elite Onboarding Wizard**: A multi-step registration flow (Steps 1–5) that captures user data while maintaining engagement through progress indicators.
- **Strategic Goal Setting**: Interactive selection of primary objectives, including Lose Weight, Build Muscle, Keep Fit, and Increase Endurance.
- **Intensity Profiling**: Analysis of activity levels (Sedentary to Athlete) to calculate accurate caloric targets and rest periods.
- **Secure Authentication**: Integrated email registration with password confirmation and social login support for Google and iOS.
- **Visual Progress Tracking**: Real-time visual feedback via a cyan progress bar at the top of the interface during setup.
- **Terms and Privacy Compliance**: Built-in legal agreement toggles during account creation to ensure data privacy standards.
### User Flow & Activities
- **Primary User Journey**: The user begins at
- the Splash Screen(Welcome Screen),
- navigates through User Registration,
- completes the Goal Selection,
- defines their Activity Level, and
- finally arrives at the Personalized Dashboard for daily logging.
